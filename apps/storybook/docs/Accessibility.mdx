# Accessibility

The design system targets WCAG 2.2 AA.

Interactive components must support visible focus, keyboard operation, screen
reader semantics, disabled states, error states, and reduced-motion preferences.

Automated checks run through Storybook's accessibility addon. Manual testing is
still required for keyboard flows, focus restoration, screen reader behavior, and
high-contrast review.
